# 市面监控系统对比调研：数据怎么关联、操作怎么做

> 调研对象：海康 iSecure Center（iSC）、大华 DSS、Milestone XProtect、Frigate、Synology/UniFi。
> 结论先行：**主流平台的资产核心全部是"通道/监控点"，设备只是通道的载体容器**——与我们收敛后的模型一致。
> 行业惯例操作顺序是"先在前端（NVR/IPC）配好，平台只做汇聚"，与你的直觉（摄像机挂 NVR）完全一致。

---

## 一、各家怎么关联（数据模型）

### 海康 iSecure Center（国内市占最高）
- 添加对象叫**编码设备**（NVR 或 IPC）：系统管理→设备管理→视频监控→添加，选 IP 方式或 GB28181 方式，填 IP/端口/账密，在线检测。
- 添加后平台**自动拉取下级通道**，通道即"**监控点**"，批量分配到**组织**（部门树）。
- 录像计划在配置中心配，关键动作是计划里选「**设备存储**」（存 NVR）还是中心存储/云存储——**计划模板 × 存储位置**两个概念。
- 经验共识（CSDN 实录）：**先在 NVR 网页把摄像机配好，再把 NVR 加进平台，"一般不对 NVR 执行累加操作"**。

### 大华 DSS
- 基础管理→设备管理→添加：IP 直连 / **主动注册**（设备侧发起，穿透 NAT）/ GB28181，填账密 + **视频通道数**，等设备上报 3~5 分钟在线。
- 通道在"逻辑组织"里挂树；存储服务（存储立方/NVR）配好后对通道下发存储计划。

### Milestone XProtect（海外企业级标杆）
- 层级固定为 **Recording Server → Hardware（一台硬件）→ Channels（视频/音频/元数据）**。
- 添加硬件有向导**自动探测**（ONVIF/驱动），列出该硬件所有通道供勾选。
- 官方明确警告：**删除硬件 = 连带删除其下所有摄像头、麦克风和全部录像**——和我们"删载体连带通道"的级联语义相同（方向相反：他们硬件是容器删子全部，我们通道是核心、载体影子化）。

### Frigate（开源 AI NVR）
- 无"设备"概念，一台摄像机 = 一段 YAML：**detect 流（低清，喂 AI）+ record 流（高清，零解码直存）** 双码流。
- **快照/事件按"目标"生成**：画面里没人就不产生快照；录像支持事件前后 pre/post capture。

### Synology Surveillance Station / UniFi Protect（消费/准专业）
- 添加摄像机 = 贴 RTSP 地址（UniFi 开 RTSP 后复制 token URL），选品牌或 User defined。
- 录像计划三选一：**Continuous / 移动侦测 / 人车检测**，按星期×时段表；时间轴（Timeline）回放是核心交互。
- 玩法：**双路录像**——一路连续存档、一路事件流（省空间又全量可回溯）。

## 三、结论：我们和主流的差异

**模型层面（我们已对齐，不需要改）：**
1. 通道为核心资产、设备只是载体 —— 与 iSC/Milestone/DSS 完全同构。
2. 录像 = 存储位置 × 时间表 —— 我们的「录像归属 + 录像计划」即 iSC 的「存储类型 + 计划模板」。
3. 行业默认姿势"摄像机挂 NVR、平台汇聚" —— 我们的 NVR 挂载/取流/云台/归属链路完整支持，同时保留了直连 ZLM 的轻量路线（iSC 的中心存储等价物）。

**值得吸收的 4 个点（按优先级）：**
1. **双码流**：识别/预览拉子码流（省带宽、省算力），录像存主码流（清晰）。我们目前只拉 102 子码流——向导已采集 subtype 参数，扩展成"识别码流/录像码流"两个代理任务即可。
2. **事件驱动录像（pre/post capture）**：识别出 ABNORMAL 时自动保存前后 N 秒片段，作为告警证据——比"事后翻 7×24 录像"高效得多。定时任务阶段顺带实现。
3. **ONVIF 自动发现**：向导里加"扫描网段"一步（ONVIF 探测出 IP/型号/通道，勾选接入），替代手填 8 项。ONVIF 是行业标准，海康/大华/宇视都支持。
4. **时间轴回放**：回放页从"列表+日期"升级为 24 小时时间轴条（有录像的时段高亮，拖拽即播）。cloud_record 的起止时间字段已够用，纯前端工作。

**我们不追的（理由）：**
- 中心存储池/云存储集群（iSC CVR）：我们单站点巡检场景，ZLM 单节点 + NVR 分布已够；`storage-nodes` 概念已留好扩展位。
- 设备级联动布防/撤防等安防行业特性：巡检平台不以安防告警为主业。
